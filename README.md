# *Aplicação back-end com Node.Js, Express e PostgreSQL*

> Este é um projeto de aprendizado de Node.Js com o uso do Express e Sequelize para criação de Rotas, Models e Controllers com integração ao banco de dados PostgreSQL, além de outras funcionalidades comuns no back-end como padronização e estilização com Prettier, Eslint e ConfigEditor e verificação de rotas no Insomnia.
